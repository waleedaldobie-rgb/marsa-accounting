# Sprint 19 — REST API

## النطاق

أضيفت طبقة REST API باستخدام Django REST Framework فوق خدمات الدومين الموجودة، من دون نقل منطق الأعمال إلى الـ views أو تكراره في الـ serializers. جميع المسارات الجديدة تبدأ من `/api/v1/`.

## المصادقة

المصادقة باستخدام Token Authentication. يحصل العميل على token من:

```text
POST /api/v1/auth/token/
```

مع `username` و`password`، ثم يرسل:

```text
Authorization: Token <token>
```

جميع موارد الـ API تتطلب مستخدمًا مصادقًا عليه، باستثناء نقطة الحصول على token.

## الموارد

تشمل الطبقة الحالية الكتالوج والأسعار والموردين والفروع والمواقع، أرصدة وحركات المخزون، المشتريات ومرتجعاتها، الورديات والمبيعات وإصدار البيع ومرتجعات المبيعات، التحويلات وإرسالها واستلامها، المصروفات واعتمادها، ملخص وإغلاق الوردية، وتقارير المبيعات والمخزون والربحية والمصروفات.

## قواعد الحماية

الحقول الحساسة مثل `invoice_no` و`status` و`total` و`cogs` و`unit_cost` وحقول الاعتماد والتدقيق للقراءة فقط. عمليات إنشاء وإصدار واعتماد المستندات تستدعي خدمات الدومين الحالية، بما في ذلك `create_sale_draft` و`issue_sale` و`approve_purchase` و`send_transfer` و`receive_transfer` و`approve_expense` و`approve_closing`.

يطبق الـ API عزل الفروع على الاستعلامات والعمليات، ويتحقق من الدور والملكية والصلاحية على الخادم. لا يعتمد على الواجهة الأمامية في حماية البيانات.

## الاختبارات

أضيفت اختبارات للمصادقة، الوصول غير المصرح، token و`/me/`، عزل الفروع في المخزون، التحقق من الوزن الخام/المنظف، إنشاء وإصدار البيع، ومنع إصدار مستند فرع آخر. شغلت الاختبارات داخل PostgreSQL عبر Docker ونجحت جميع الاختبارات المتاحة.
