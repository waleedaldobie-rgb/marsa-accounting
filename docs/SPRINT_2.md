## Implemented
- Custom User roles: Owner, Accountant, Branch Manager, Cashier.
- Branch and Location validation.
- Server-side permission helpers.
- Server-side branch scoping helpers.
- Seed command for two branches and central warehouse.
- Initial RTL application shell and login/dashboard UI.

## Rules
- Owner can access all branches.
- Non-owner users are scoped to their assigned branch.
- A user without a branch gets no branch-scoped records rather than all records.
- UI visibility is not security; views/services must enforce permissions server-side.
- No default passwords are generated by seed data.
